語彙パック エディタ

shunti Japanese IME の語彙パック (.pack) を作る・直すためのツールです。 出来上がったファイルをリポジトリの tools/vocab_packs/ に置いて Pull Request を送れば、パックとして配布できます。

品詞のはたらき / クラス指定について

品詞を指定すると、変換エンジンの接続コスト行列で正しい品詞として扱われ、文の途中に混ざったときの区切り方がまともになります。 五段・一段・形容詞は活用形が自動で生えます — がばる / ガバる / 五段 と1行書けば がばって→ガバって、がばった→ガバった、がばらない→ガバらない まで引けます。

品詞用途活用
五段 / 一段動詞。る で終わる語は字面で区別できないので必須あり
形容詞い形容詞 (めろい、やばい)あり
な形容詞静か、ぐう聖—
サ変名詞〜する が付く名詞—
人名 / 地名 / 組織固有名詞—
その他代名詞 / 数 / 助数詞 / 非自立名詞 / 副詞可能 / 外来語 / 副詞 / 感動詞 / 接頭辞 / 接尾辞 / 記号—

品詞で足りないときは「クラス」欄に @34 (左右とも34) や @0,10 (左0・右10) と書くと、 接続行列のクラスIDを直接指定できます。左右で分けられるのは、活用語が「前から見た顔」と「次へ渡す顔」で別のクラスを持つためです。

優先度は 1〜10 で、小さいほど候補の前に出ます。1=最優先 / 5=3〜4番目あたり (既定) / 10=一番右でいい。

出来上がり (.pack)

区切りはタブです。この内容をそのまま tools/vocab_packs/<ファイル名>.pack として保存してください。

読み込み

既存の .pack を開いて続きから編集できます。作業内容はこの端末に自動保存されます。
