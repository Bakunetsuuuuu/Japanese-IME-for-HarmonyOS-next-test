# 語彙パック (vocab packs)

「一般語彙ではないが、ある界隈の人はめちゃくちゃ使う」語彙を、既定OFFの
追加インストール単位にまとめたもの。利用者は設定画面 → 語彙パック で
個別にON/OFFできる。

このディレクトリの `*.pack` を1つ足せば新しいパックが増える。**アプリの
コード (`.ets`) を触る必要はない** — パック名も説明文もファイルの中に
書くので、ビルドスクリプトがそのまま設定画面まで運ぶ。

## エディタ

手で書かずに作れるツールがあります。品詞や優先度を覚えなくても選ぶだけで、
書き間違いはその場で指摘されます。スマホでもPCでも使えます。

**<https://shuntilettuce.github.io/Japanese-IME-for-HarmonyOS-next/pack-editor.html>**

既存の `.pack` を開いて続きから編集することもできます。出来上がったファイルを
このディレクトリに置いて Pull Request を送ってください。

## 書き方

```
# 行頭が # の行はコメント。どこにでも書ける。
name: 淫夢語録
description: 由来と無関係な一般リアクション表現として定着したもののみ
---
かんぜんにいっち	完全に一致	1
ふぁっ	ファッ!?	1
ふぁっ	ファッ	5
がばる	ガバる	1	五段
ぐうせい	ぐう聖	1	な形容詞
-らん	LAN
```

### ヘッダ (`---` より上)

| キー | 必須 | 意味 |
|---|---|---|
| `name` | 必須 | 設定画面に出るパック名 |
| `description` | 任意 | 設定画面でパック名の下に出る一行説明 |
| `default` | 任意 | `on` にすると既定で有効。省略時は `off` |
| `pos` | 任意 | パック全体の既定品詞。全語が同じ品詞のとき1回だけ書く |

`default: on` は「今まで普通に引けていた語を切り出した」ときに使う。既定OFFに
すると、更新しただけで引けなくなり利用者から見れば機能の後退になるため。

`pos:` はパック内の全語に効く既定品詞。地名パックのように全語が同じ品詞の
場合、1語ずつ書くと生成物が語数ぶん膨らむ（実際に2万語で 1.6MB になった）。
語ごとの指定があればそちらが優先される。活用する品詞（五段・一段・形容詞）は
語ごとに書く必要があるのでここには指定できない。

### 本体 (`---` より下)

1行1エントリ。**タブ、または半角スペース2個以上**で区切る (どちらでもよい —
エディタがタブを空白に変換しても壊れない)。

```
読み	単語	[オプション...]
```

- **読み**: ひらがな
- **単語**: 変換先の表記
- **オプション**: 0個以上。**順不同**で、書き方から種類を判別する。

| 書き方 | 意味 |
|---|---|
| `1`〜`10` | 優先度 (省略時 5) |
| `五段` `形容詞` など | 品詞 (省略時 名詞) |
| `@12` `@0,10` | 接続行列のクラスIDを直接指定 |

つまり最小限なら `読み	単語` の2列だけでよく、必要な人だけ後ろに足していく。

### コメント

行頭の `#` はその行全体、オプション列に現れた `#` はそこから行末までが
コメントになる。`#` の後のスペースは要らない。

```
#見出しや方針をまとめて書くとき
がばる	ガバる	1	五段	#語源は「ガバガバ」
わいし	ワイ氏	#2列だけの行にも付けられる
```

読みと単語の列は切られないので、`しゃーぷ	#` のように記号そのものを
登録しても壊れない。

#### 優先度の目安

小さいほど前 (左) に出る。

| 値 | 意味 |
|---|---|
| 1 | 最優先。その読みを打ったら真っ先に出てほしい |
| 5 | 3〜4番目あたりに出てほしい (省略時の既定) |
| 10 | 一番右のほうにあればいい。滅多に使わないが一応欲しい |

同じ優先度なら書いた順。同じ読みを複数行書いてよい。

### 品詞

省略したら名詞。指定すると変換エンジンの接続コスト行列で正しい品詞として
扱われ、文の途中に混ざったときの区切り方がまともになる。

**動詞・形容詞は活用形が自動で生える。** `がばる	ガバる	五段` と1行書けば
`がばって`→ガバって、`がばった`→ガバった、`がばらない`→ガバらない … まで
全部引けるようになる (ユーザー辞書の品詞登録とまったく同じ仕組み)。

| 品詞名 | 用途 | 活用展開 |
|---|---|---|
| `名詞` | 既定。指定しなくてよい | — |
| `五段` | 五段動詞 (がばる、わかる) | ✅ |
| `一段` | 一段動詞 (たべる、みる) | ✅ |
| `形容詞` | い形容詞 (めろい、やばい) | ✅ |
| `な形容詞` / `形容動詞` | 静か、ぐう聖 | — |
| `サ変名詞` | 〜する が付く名詞 (勉強、お気持ち表明) | — |
| `人名` `地名` `組織` | 固有名詞 | — |
| `代名詞` `数` `助数詞` | | — |
| `非自立名詞` | こと、もの、とき | — |
| `副詞可能` | 今、前、後 | — |
| `外来語` | アプリ、ファイル | — |
| `副詞` `感動詞` `接頭辞` `接尾辞` `記号` | | — |

> 五段/一段の区別は、`る` で終わる語が字面では判別できないため必須。
> `る` 以外で終わる動詞も、活用させたいなら `五段` と書く。

### 接続行列クラスの直接指定 (`@`)

上の品詞名で足りないときの逃げ道。`@` に続けてクラスIDを書くと、接続コスト
行列のクラスを直接指定できる。

```
えもい	エモい	@34        左右とも 34 (い形-基本形)
なんか	なんか	@0,10      左クラス0・右クラス10
```

クラスIDの一覧は [`tools/gen_matrix_default.py`](../gen_matrix_default.py)
冒頭のコメントにある (0-13 名詞 / 14-33 動詞 / 34-41 形容詞 / 42-47 副詞 /
48-72 助詞 / 73-86 助動詞 / 87-89 接続詞 / 90-97 その他)。

左右で分けられるのは、活用語が「前から見た顔」と「次へ渡す顔」で別のクラスを
持つため。例えば「食べた」は左が動詞(22)、右がた形(25)で、だから「食べたが」は
繋がるのに「食べたます」は繋がらない。品詞名を書けば普通はこれを意識しなくて
よく、`@` は本当に細かく効かせたいときだけ使う。

#### 候補の抑制 (`-`)

行頭に `-` を付けると、その候補を**出さない**指定になる。優先度は書かない。

```
-らん	LAN
```

パックを有効にしている間だけ効く。「この界隈ではこの変換が邪魔」という
ときに使う。

## ビルド

```bash
python3 tools/build_vocab_packs.py            # 全パックをビルド
python3 tools/build_vocab_packs.py --report   # 読み込んで内容を表示するだけ
```

語彙そのものは本体の辞書と同じバイナリ形式で `rawfile/pack_<ID>.*` に、
一覧（名前・説明・既定ON/OFF・語数・品詞・抑制）は
`rawfile/pack_manifest.json` に書き出す。**パックを足したらビルドし直して、
生成物も一緒にコミットすること**。

> アプリは起動時に manifest だけを読み、**有効なパックの語彙バイナリだけ**を
> 後から読む。最初は「パックは小さいから JSON のままでいい」としていたが、
> 地名を地方別に分ける段で2万語規模のパックが出てきたため載せ替えた。
> JSON のままだと有効・無効に関わらず全パックが JS オブジェクトへ展開され、
> パックに分けた意味が無くなる。

## 地名パックについて

`place_*.pack` は [`tools/build_place_packs.py`](../build_place_packs.py) が
日本郵便の郵便番号データから生成しているので、**手で編集しない**。
生成し直す手順はそのスクリプトの docstring にある。
