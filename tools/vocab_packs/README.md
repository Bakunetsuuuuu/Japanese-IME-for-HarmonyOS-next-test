# 語彙パック (vocab packs)

「一般語彙ではないが、ある界隈の人はめちゃくちゃ使う」語彙を、既定OFFの
追加インストール単位にまとめたもの。利用者は設定画面 → 語彙パック で
個別にON/OFFできる。

このディレクトリの `*.pack` を1つ足せば新しいパックが増える。**アプリの
コード (`.ets`) を触る必要はない** — パック名も説明文もファイルの中に
書くので、ビルドスクリプトがそのまま設定画面まで運ぶ。

## 書き方

```
# 行頭が # の行はコメント。どこにでも書ける。
name: 淫夢語録
description: 由来と無関係な一般リアクション表現として定着したもののみ
---
かんぜんにいっち	完全に一致	1
ふぁっ	ファッ!?	1
ふぁっ	ファッ	5
がばる	ガバる	1	五段
ぐうせい	ぐう聖	1	な形容詞
-らん	LAN
```

### ヘッダ (`---` より上)

| キー | 必須 | 意味 |
|---|---|---|
| `name` | 必須 | 設定画面に出るパック名 |
| `description` | 任意 | 設定画面でパック名の下に出る一行説明 |

### 本体 (`---` より下)

1行1エントリ。**タブ、または半角スペース2個以上**で区切る (どちらでもよい —
エディタがタブを空白に変換しても壊れない)。

```
読み	単語	[オプション...]
```

- **読み**: ひらがな
- **単語**: 変換先の表記
- **オプション**: 0個以上。**順不同**で、書き方から種類を判別する。

| 書き方 | 意味 |
|---|---|
| `1`〜`10` | 優先度 (省略時 5) |
| `五段` `形容詞` など | 品詞 (省略時 名詞) |
| `@12` `@0,10` | 接続行列のクラスIDを直接指定 |

つまり最小限なら `読み	単語` の2列だけでよく、必要な人だけ後ろに足していく。

#### 優先度の目安

小さいほど前 (左) に出る。

| 値 | 意味 |
|---|---|
| 1 | 最優先。その読みを打ったら真っ先に出てほしい |
| 5 | 3〜4番目あたりに出てほしい (省略時の既定) |
| 10 | 一番右のほうにあればいい。滅多に使わないが一応欲しい |

同じ優先度なら書いた順。同じ読みを複数行書いてよい。

### 品詞

省略したら名詞。指定すると変換エンジンの接続コスト行列で正しい品詞として
扱われ、文の途中に混ざったときの区切り方がまともになる。

**動詞・形容詞は活用形が自動で生える。** `がばる	ガバる	五段` と1行書けば
`がばって`→ガバって、`がばった`→ガバった、`がばらない`→ガバらない … まで
全部引けるようになる (ユーザー辞書の品詞登録とまったく同じ仕組み)。

| 品詞名 | 用途 | 活用展開 |
|---|---|---|
| `名詞` | 既定。指定しなくてよい | — |
| `五段` | 五段動詞 (がばる、わかる) | ✅ |
| `一段` | 一段動詞 (たべる、みる) | ✅ |
| `形容詞` | い形容詞 (めろい、やばい) | ✅ |
| `な形容詞` / `形容動詞` | 静か、ぐう聖 | — |
| `サ変名詞` | 〜する が付く名詞 (勉強、お気持ち表明) | — |
| `人名` `地名` `組織` | 固有名詞 | — |
| `代名詞` `数` `助数詞` | | — |
| `非自立名詞` | こと、もの、とき | — |
| `副詞可能` | 今、前、後 | — |
| `外来語` | アプリ、ファイル | — |
| `副詞` `感動詞` `接頭辞` `接尾辞` `記号` | | — |

> 五段/一段の区別は、`る` で終わる語が字面では判別できないため必須。
> `る` 以外で終わる動詞も、活用させたいなら `五段` と書く。

### 接続行列クラスの直接指定 (`@`)

上の品詞名で足りないときの逃げ道。`@` に続けてクラスIDを書くと、接続コスト
行列のクラスを直接指定できる。

```
えもい	エモい	@34        左右とも 34 (い形-基本形)
なんか	なんか	@0,10      左クラス0・右クラス10
```

クラスIDの一覧は [`tools/gen_matrix_default.py`](../gen_matrix_default.py)
冒頭のコメントにある (0-13 名詞 / 14-33 動詞 / 34-41 形容詞 / 42-47 副詞 /
48-72 助詞 / 73-86 助動詞 / 87-89 接続詞 / 90-97 その他)。

左右で分けられるのは、活用語が「前から見た顔」と「次へ渡す顔」で別のクラスを
持つため。例えば「食べた」は左が動詞(22)、右がた形(25)で、だから「食べたが」は
繋がるのに「食べたます」は繋がらない。品詞名を書けば普通はこれを意識しなくて
よく、`@` は本当に細かく効かせたいときだけ使う。

#### 候補の抑制 (`-`)

行頭に `-` を付けると、その候補を**出さない**指定になる。優先度は書かない。

```
-らん	LAN
```

パックを有効にしている間だけ効く。「この界隈ではこの変換が邪魔」という
ときに使う。

## ビルド

```bash
python3 tools/build_vocab_packs.py            # 全パックをビルド
python3 tools/build_vocab_packs.py --report   # 読み込んで内容を表示するだけ
```

全パックをまとめて `entry/src/main/resources/rawfile/pack_manifest.json` に
書き出す。アプリはこれを読んで設定画面の一覧・語彙・品詞をすべて組み立てる
ので、**パックを足したらビルドし直して、生成物も一緒にコミットすること**。

> 本体の辞書 (dict/global_dict) は10万〜28万読みあるのでバイナリ化が必須
> だが、語彙パックは「界隈の定番語彙」という性質上そこまで大きくならないし、
> 活用展開を実行時に行う都合でどのみち展開が要るので、JSON 1本にしてある。
